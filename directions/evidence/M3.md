# M3 sphere primitive evidence

This milestone adds pure hour-angle, semi-arc and quadrant calculations to the
directions workbench based on the engine checkout at `296dc42`. No directional
contact or directed age is calculated. The engine source, root package and
build output are unchanged.

## Independent references

[M3-derivations.md](M3-derivations.md) derives the geometry from a unit vector
and geometric horizon, with the US Naval Observatory's altitude relation as
an independent published definition. Ptolemy's temporal-hour construction is
cited for proportional meridian distances. The new library coordinate's
orientation is stated explicitly; it is not attributed as an aspect rule to
those sources.

[sphere-examples.ts](sphere-examples.ts) contains authored symbolic fixtures.
Its declination expression specifies an invented input with tangent equal
to a simple rational. Expected hour angles, ascensional differences, semi-arcs,
quadrant fractions and proportional coordinates follow from the written
derivation. They are not recorded solver output or ephemeris positions.

[sphere.check.ts](../checks/sphere.check.ts) compares the library against those
fixtures using the allowances fixed in the fixture file before the solver
was run. They apply only to the named examples, not to every accepted input.
The tests also enforce exact labels at equatorial meridians and horizons,
wraparound, both latitude signs, polar and circumpolar refusals, and
off-midpoint quadrant fractions. No physical accuracy or prediction claim
follows from these geometric checks.

## Numerical boundaries

The domain comparison uses the smaller coordinate magnitude against the
complement of the larger, so a rounded sum cannot hide a crossing or a
circumpolar point. The tests place declination immediately inside and outside
the exact complementary boundary with representable binary offsets. Those
checks establish refusal behavior and nonzero arcs, not a measured angular
error for arbitrarily close tangencies.

The factored atan2 derivation retains the short semi-arc directly. It neither
clamps an invalid inverse-trigonometric argument nor silently substitutes a
polar system. Geographic poles, celestial poles, tangencies, always-above and
always-below points are distinct typed refusals. An unresolved floating-point
calculation has its own defensive refusal.

Axis membership is decided from the computed hour angle and diurnal semi-arc
with no epsilon. Near-axis tests check that a nearby quadrant is retained.
Binary64 rounding can place a reported fraction or proportional coordinate
on an axis even while the quadrant discriminator remains interior. The
README documents this limitation. Oblique fixtures avoid claiming exact
horizon membership after trigonometric rounding.

## Ownership and scope

The helpers accept explicit degree coordinates and return deeply frozen data.
They do not mutate or freeze the input object, read accessors, coerce strings,
or infer omitted fields. Runtime and compile checks cover those contracts.
The public pure entry imports no ephemeris; the natal adapter remains opt-in.
Latitude projection, aspect branches, direction motion and timing keys belong
to later milestones and are not selected by these coordinate helpers.

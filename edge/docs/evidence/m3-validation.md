The deadline check uses Node's mock timers, which emit an experimental API

## What was checked

`tests/http.check.mjs` imports the self-contained Worker bundle in Node and
compares its full chart JSON to a separate Node source build. The inputs are
the synthetic chart corpus in `src/workloads.ts`, plus date-only and offset
forms, UT1 and TT settings, unknown time, and every exported house system at
the synthetic northern location. Global fetch throws during the calculation
test, and no outbound call occurs. Comparisons use strict equality after
ordinary JSON serialization on both sides. They do not preserve Date objects
or signed zero and are not cross-runtime binary64 checks.

The same test file exercises routing, HEAD response bodies, response headers,
JSON media types and charset variants, content encoding, malformed JSON and
UTF-8, supported fields, coordinate boundaries, paired coordinates, finite
numbers, inherited-name keys and unknown settings. Engine date/span refusals
are checked against fixed HTTP error responses. An injected calculator tests
unexpected exceptions and serialization failures without leaking their
details or submitted input values.

The byte, chunk, instant-string and deadline limits in `HTTP_LIMITS` are
asserted with fixed values in the tests. Cases cover the limits themselves
and excess input, Content-Length missing or understated, a declared oversize
body rejected without pulling, multibyte byte accounting, a UTF-8 code point
split between chunks, always-ready empty chunks, aborted/consumed/locked
bodies and stream failures. Cancellation is checked with successful,
rejected and never-settling cancellation promises. Rejected input never
reaches the calculator in the validation tests.

`tests/bundles.check.mjs` continues to check repeated-build byte equality,
source and output digests, import graphs, file sizes and preserved notices.
It now verifies that only the Workers target includes the Worker entry and
its HTTP source, that the output exports only the default handler, and that
the handler's response matches the synthetic chart corpus under Node. The
foundation tests continue to check charts, houses and the bounded transit
scan. The build report is generated by `scripts/build-report.mjs` and records
build sizes and hashes only, not performance measurements.

## Scope and remaining checks

This milestone implements the Worker module and its shared request contract.
Workers, Deno, Bun and a real browser were not executed. There was no socket
server, remote deployment, runtime CPU measurement or cross-runtime parity
claim. Deno/Bun handlers remain in M4; the exact comparison protocol and
runtime runs remain in M5 through M7. Compatibility checks here do not
establish astronomical accuracy.

All edits and generated outputs stayed under `edge/`. Root source, packed
files, dependencies, build output and release archives were unchanged. No
archive was packed. The root CI and archive rebuild gates were not run, and
the isolation check does not substitute for the failing root package-content
gate. Root `dist/` was left absent in accordance with this project's scope.

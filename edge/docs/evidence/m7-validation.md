## Native results and measured scope

The synthetic input corpus remains `src/workloads.ts`: chart cases
`whole-utc`, `southern-placidus`, `polar-koch` and `untimed`; its northern,
southern and polar house inputs across `HOUSE_SYSTEMS`; and `TRANSIT_CASE`,
the Sun longitude scan from `2000-03-01T00:00:00Z` to
`2000-04-01T00:00:00Z`. Every field in the returned result trees is compared
through `src/exact.ts`. No external ephemeris comparison or astronomical
accuracy claim is made.

All selected runtimes completed the workloads and repeated their own exact
results. The Node and workerd exact-result SHA-256 values are equal in
`m7-web.json`. The Workers adapter also imported the engine, workload and
handler modules, checked their exports against Node, and matched Node's
statuses, selected headers and body strings for all 11 HTTP cases. The cases
are defined by `evaluateWorkerModules` in `scripts/smoke-workers.mjs`: the
synthetic charts plus route, method, HEAD, malformed JSON, invalid input,
invalid date and oversized body checks. This is local workerd evidence, not
a deployed Cloudflare test.

Chrome loaded the public engine and workloads as browser ESM over loopback,
verified exports against the build graph, and checked that its direct engine
chart exactly matched the corresponding workload chart. Full results differed
from Node. The first mismatch, as generated by the exact comparator, is:

| Original result path | Node binary64 | Chrome binary64 |
| --- | --- | --- |
| `$["charts"][0]["result"]["bodies"][1]["speed"]` | `402afaac235bd1c0` | `402afaac235bf100` |

These bit patterns come directly from `m7-web.json`. No value is rounded or
replaced to produce agreement. Fields after that first mismatch are not
claimed to match. This measurement does not isolate which underlying math
operation caused the difference. The combined web parity gate is failing on
this tested matrix. M7 delivers the checker and records that result; it does
not make Chrome or the earlier Deno/Bun runs numerically equal to Node.

## Network and runner checks

The report records no unexpected workerd requests under the pre-import fetch
guard and Miniflare's outbound denying service. A deliberate native-fetch
probe verified the service. Cloudflare metadata fetching was disabled. Native
tests also prove that a swallowed fetch error during import or calculation
still fails the adapter. Import failures, missing exports, nonrepeatability,
handler-only differences, a hung workerd and pre-aborted runs are covered.

Chrome's permitted traffic was the loopback page and its named ESM bootstrap
assets. Guards installed before imports, browser request routing and blocked
service workers detected no unexpected import or calculation requests.
Intentional fetch and image requests were denied without reaching the local
server. Browser tests cover swallowed network calls, unexpected resource
requests, import errors, malformed exact transport, changed repeats and a
direct-engine/workload disagreement. This observation covers the tested page
and synchronous calculations, not browser background services or arbitrary
future timers. It is not an operating-system network sandbox.

The browser lifecycle tests wait for Chromium's process identity after module
imports, then hang a calculation. Timeout and active interruption each stop
the started Chromium process, close the loopback server and remove the
temporary profile directory. The driver exits while Playwright's process exit
hook can terminate Chromium's separate process group. Both browser and Workers
launchers use the bounded process runner. Its added child-only temporary
directory option is tested for edge-cache containment, symlink rejection and
an unchanged parent environment. Windows process-tree cleanup is untested.

The web suite tests also require failure for exact one-bit, signed-zero and
Date changes, HTTP-only mismatches, missing references, malformed reports,
failed network checks, missing browser executables and invalid CLI options.
Its Node-only success case explicitly lists Workers and browser as unselected.
Missing tools cannot be counted as tested.

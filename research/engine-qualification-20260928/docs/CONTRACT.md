# Frozen plan and evidence contract

The three commands intentionally separate inspection, input commitment and execution. Inspection and planning read files and resolve package entry paths without importing either engine. Execution imports each target only inside a separate process and runs baseline then candidate sequentially.

`data/protocol.json` is pinned by both byte hash and canonical digest in `src/protocol.mjs`. `data/reference-contract.json` is byte-pinned in `src/references.mjs` and pins every consumed reference input. The normalized reference digest binds rows, source receipts, conventions and limitations. Changes require a new reviewed experiment; the CLI offers no flag for weakening thresholds or skipping rows/probes.

A plan contains the full baseline/candidate identities, the operator's candidate declaration, the frozen baseline declaration, all 12 probes, the policy, reference digest and the harness file map. The run requires an independently retained expected hash of the **exact plan file bytes**. Local timestamps and unsigned hashes cannot prove an external preregistration, publication date, publisher identity or source ancestry.

Installed artifact identity covers all regular files beneath the standalone package, including every installed `node_modules` file; `.git` metadata is excluded. Declared runtime, optional and peer dependencies are resolved recursively from each installed package's own location and must remain inside the root. Missing optional dependencies are conservatively rejected. Symlinks, special files, more than 20,000 files or more than 256 MiB are unsupported. The smaller 64 MiB budget is a separate performance/distribution diagnostic. Dynamic imports outside the declared installation and transient modifications are not authenticated by this inventory.

The worker protocol is bounded newline-delimited JSON. Missing/duplicate/unknown IDs, altered observation metadata, invalid coordinates, malformed or excessive output, and abnormal exit prevent an execution pass. Every expected result gets an explicit row, including errors. Surviving partial rows can be shown for diagnosis; they never establish complete coverage. V8 old-space is capped at 256 MiB by the default command, but total RSS, native memory and operating-system capabilities are not sandboxed.

The reference suite uses synthetic UT1 encoded in ISO Z strings and a constant 69-second DeltaT pin. Each result is checked against its requested body, encoded instant and pin. Reference time labels are not a historical/future UTC service. Moon reference positions are geometric; other selected positions use JPL LT+S. Outer-planet references use planetary-system barycenters. The independent ERFA orientation is not identical to every candidate implementation. Declarations describe the selected reference and claimed implementation separately.

The evaluator refuses altered policy objects. Complete baseline and candidate results are required for per-coordinate nonregression. A complete candidate can have an independently reported target result even if the baseline fails, but overall checks still fail and no relative claim is made. Missing observations never reduce the 210-row target denominator. Timing must cover all 21 unique epoch/pin calls. Required function types, export names and aspect policy are checked independently of positional numbers.

The JSON report includes all comparison rows, per-body aggregates, gates, declared differences, runtime environment, process outcomes and a review checklist. `numericalDigest` excludes run timestamps and timing. `reportDigest` hashes the entire report before the digest field is added. `run-manifest.json` hashes the files written before the manifest itself; it is not self-authenticating or signed. Reusing an output directory is refused.

Every result, including all-pass synthetic controls, retains `adapterReviewRequired: true`, `adapterQualified: false`, and `releaseAuthorized: false`. Inspection, planning and this evaluation do not modify engine files, production Verify inventories or release configuration.

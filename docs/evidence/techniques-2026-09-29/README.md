# Techniques entry point: results

The gates of [`PREREGISTRATION.md`](PREREGISTRATION.md), committed in
`d3bfca4` before any code of `@zodiacs/engine/techniques` existed, measured on
`19719ce` (branch `feature-techniques`) with Node v22.22.2 (tzdata 2025c). The
package version is unchanged, 0.1.1-rc.15. The commits after `930ef6b`, which
added the entry point, change only comments, documentation and this
directory; the built `dist/` is the same.

Two gates are recorded as failed. G1 fails on one case of 6,796: a date that
did not occur in its time zone, which the site answers and the package
refuses. G6 fails as run in this session: 23 existing tests fail because the
check they test refuses the session's temporary directory; they pass with
another one. The details are below. The other gates pass.

To reproduce:

```sh

node docs/evidence/techniques-2026-09-29/site-parity.mjs \
  --snapshot "$SCRATCH/site" --engine "$SCRATCH/engine/package" \
  --work "$SCRATCH/work" --out "$SCRATCH/out"

# The measurements, on the built package (TMPDIR outside the checkout).
npm run build
node docs/evidence/techniques-2026-09-29/measure.mjs > measurements.json
```

archive, the engine the package ports them into, so a difference comes from
the port and not from the ephemeris. How the site's code behaves on rc.10 was

Where an agreement is counted, instants agree to the millisecond, numbers as
doubles, and names, identifiers and lists in order; each input the site
refuses, the package refuses with a `RangeError`. A return chart is compared by
its bodies, angles, cusps, aspects, flags and ΔT.

The disagreement is M-Z case 1522: 2011-12-30 in Pacific/Apia
(`zonedDisagreements` in `measurements.json`), a date the zone skipped. The
site reads the date's first midnight forward across the gap, to
2011-12-30T10:00:00.000Z, which is 00:00 at UTC+14, and its last millisecond
as 2011-12-30T09:59:59.999Z, one millisecond before its start, and names
Pisces. The package refuses the date ("The date did not occur in that time
zone."). Over the site's own endpoints the package's `moonSignsBetween`
refuses the inverted span as well, so the case also differs in the corpus's
second M-Z comparison, which reads only the Moon signs. The refusal was
chosen when the port was written; the gate did not allow it, so G1 is
recorded as failed.

Recorded without a pass condition:

- **R-E**, 40 return windows that reach outside 1800–2200, where the site
  clips its scans and refuses beyond: 6 cases agree; in 28 the site refuses
  and the package answers (7 `solarReturnInstant`, 6
  `mostRecentSolarReturnInstant`, 10 `lunarReturnInstant`, 5

  answers of all 34 are `edgeCases` in `measurements.json`.

### G6: existing behaviour

No existing file under `src/` changed: `git diff eb58011` lists 22 added
files there and no other (`measurements.json`, `G6`).

`npm test` in `gates.log` passes 3,220 tests and fails 23, all in
`scripts/verify-archive-binding.test.mjs`. The check under test refuses a
temporary directory with a `node_modules` or `package.json` above it, and the
temporary directory this session was told to use lies under a directory that
holds a `node_modules` link outside this work. Neither that test file nor the
script it tests has changed since `eb58011`, and the refusal depends only on
the directories above the temporary one. With a temporary directory that has
no `node_modules` above it, the 23 tests pass on this branch
(`archive-binding-tests.log`, run before commit `930ef6b` was made). All the
other tests pass. The gate asks that every existing test pass; as run with
the session's temporary directory they did not, so G6 is recorded as failed.

### G7: dates before 1970

Of the 500 M-P dates, 493 agree. The 7 others are all in Europe/Stockholm,
from 1818 to 1888 (`G7.rows` in `measurements.json`). The site reads their
midnights on the host's `Intl` data at UTC+0:53:28, and for each of the 7 that
is the midnight the package gives for the same date in Europe/Berlin: on
these dates the host's data read Stockholm as Berlin. The package reads its
shipped tzdata 2025c with backzone, where Stockholm has its own offsets:
+1:12:12 for the 5 dates from 1818 to 1867 and +1:00:14 for the 2 in 1879
and 1888. The midnights differ by 18 min 44 s or 6 min 46 s, and the Moon
signs agree in all 7. Every disagreement is a different midnight, so G7
passes.

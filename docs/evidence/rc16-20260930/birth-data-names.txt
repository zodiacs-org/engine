# The birth-data check of rc.16: names only
#
# A review aid, kept outside the repository because its output holds the
# lines it matches, listed every line added by each commit of
# 93ebae9..aba647e and by the staged changes of the source commit, that holds a
# year from 1700 to 2029 beside birth vocabulary (born, birth, birthday,
# native, nativity, died, podcast, celebrity and the like) or beside a
# capitalized pair of words, and every capitalized pair of words; each hit was
# read by hand. The people it found, and why each may be there, follow. No
# line added by any of these commits holds a real person's birth data.

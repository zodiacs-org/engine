## 2.0.0 (cut 2026-11-21)

A major release: 2.0.0-rc.6 with the version changed, cut on 2026-11-21.
Checks: `docs/evidence/2.0.0-20261121/`. Callers moving from 1.1.0 should
read `docs/migrating-to-2.md` (held by `src/migration-2.0.test.ts`).

- **No code or value changes from 2.0.0-rc.6.** The only change under `src/`
  is the version string (`ENGINE_VERSION`, the two tests and the fixture that
  hold it), and `dist/` is 2.0.0-rc.6's but for that string
  (`docs/evidence/2.0.0-20261121/results/dist-vs-rc6.txt`, 95 files).
- **What 2.0.0 is over 1.1.0.** The entries below, 2.0.0-rc.1 to 2.0.0-rc.6,
  are its history:
  - **Input refusals (breaking):** a birth given as a calendar date with no
    time is refused unless `timeKnown` is `false` (2.0.0-rc.1); common
    near-miss birth keys such as `lat`, `lng`, `houses` and `scale` are
    refused instead of ignored (2.0.0-rc.3).
  - **UTC after 2027-10-02:** unpinned UTC input after the shipped IERS UT1
    table uses the continuous-UTC rule, `TT = UTC + 69.184 s`, with
    `TimeScale.basis: "continuous-utc"` and `ut1MinusUtc.source: "model"`
    (2.0.0-rc.3).
  - **Zone histories before 1970:** updated from tzdata 2025c to tzdata 2026f
    with `America/Yellowknife` held at 2025c by the owner's decision
    (2.0.0-rc.3).
  - **Flags:** three new `ChartFlag` values (`polar-angles` and
    `calendar-unknown` in 2.0.0-rc.1; `host-zone-data-differs` in 2.0.0-rc.3,
    with tzdata 2025c added beside 2021a as a host-probe baseline in
    2.0.0-rc.6 across 705 spans in 77 names), plus `flags` on `positions()`
    rows (2.0.0-rc.1).
  - **New entry and geo helpers:** `@zodiacs/engine/core` (the root API
    without the DE440 pack, 2.0.0-rc.3), and `julianDayNumber`,
    `dateOfJulianDayNumber` and `localMeanTimeOffset` in `@zodiacs/engine/geo`
    (2.0.0-rc.3).
  - **Errors:** `require()` of any entry point throws `ERR_ZODIACS_ESM_ONLY`
    (2.0.0-rc.4), and an unknown body name throws `RangeError` on every
    source including root crossing searches (2.0.0-rc.4, 2.0.0-rc.5).
- **Nothing deprecated is removed.** All seven `@deprecated` names remain:
  `docs/versioning.md` requires twelve months after the deprecating release,
  and 1.0.0 is from 2026-10-11.
- **Records.** 2.0.0 reads every natal record written by 0.1.1-rc.7 through
  2.0.0-rc.6 (`docs/evidence/records-2.0.0-20261120/`). 1.1.0 refuses
  2.0.0's continuous-UTC records as `unsupported_feature`; 2.0.0-rc.3 and
  2.0.0-rc.6 read 2.0.0's envelopes
  (`docs/evidence/2.0.0-20261121/results/earlier-readers.json`).
- **Conformance.** Measured on this build with Node 22.22.2 against suite
  0.3.0 (640 vectors; `conformance/RESULTS.md`,
  `conformance/results/zodiacs-engine.json`,
  `conformance/results/zodiacs-engine-astronomy-engine.json`): default DE440
  source **569 pass, 0 fail, 71 unsupported, 0 error** (L1 240/240, L2
  150/150, L3 109/110 with 1 unsupported, L4 70/140 with 70 unsupported);
  `astronomy-engine` 2.1.19 fallback **341 pass, 228 fail, 71 unsupported, 0
  error** (L1 48 pass / 192 fail, L2 150/150, L3 109/110 with 1 unsupported,
  L4 34 pass / 36 fail / 70 unsupported). Every verdict equals 2.0.0-rc.6's.
  The 71 unsupported vectors are 1 leap-second instant in L3, 30 stations in
  L4 and 40 lunations in L4 (the engine has no public station or lunation
  search API).
- **Runtimes.** Measured on this build across six runtimes on Linux x64
  (`docs/evidence/runtime-conformance-2.0.0-20261121/`, suite 0.3.0): all 569
  supported verdicts on both root and `@zodiacs/engine/core` agree with Node
  22.22.2 in Bun 1.4.4, Deno 2.9.6, Chromium 156.0.8078.4, Firefox 157.0 and
  WebKit 27.2 (verdict counts equal 2.0.0-rc.6's). Outputs are not
  bit-identical in every runtime (root: 458 of 569 identical to Node in Bun,
  Deno, Chromium and WebKit, 569 of 569 in Firefox; core: 468 in Bun and
  WebKit, 485 in Deno and Chromium, 540 in Firefox), and synthetic receipt
  digests differ from Node's where outputs differ.
- **Licence.** Ships with the four open licence questions noted (IERS EOP 20
  C04, CDS commercial use, Reid and Brunthaler, and ESA's non-commercial
  Hipparcos terms as a fourth), per the owner's decision of 2026-11-20 11:16
  Asia/Bangkok (`LICENSING.md`, `NOTICE`). No VSOP2013 series is shipped
  (`docs/evidence/2.0.0-20261121/results/vsop2013-check.log`).
- **Sizes and cap.** Measured on this build
  (`docs/evidence/2.0.0-20261121/results/package-contents.log`): all 20
  entry-point import graphs remain inside their 2.0.0-rc.6 budgets (no entry
  budget is raised). The package beside the DE440 pack is 1,462,688 bytes
  unpacked in 101 files; `TOTAL_CAP` is raised from 1,459,000 to 1,463,000
  (rounded up to the next 1,000 bytes), approved under the owner's delegation
  of 2026-11-21 15:06 Asia/Bangkok (`scripts/verify-package-contents.mjs`).

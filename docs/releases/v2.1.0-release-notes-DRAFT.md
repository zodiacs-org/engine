## 2.1.0 (cut 2026-11-23)

- **Station and lunation search.** In `@zodiacs/engine/calc`, `searchStations()`
  finds when Mercury through Pluto turn direct or retrograde. `searchLunations()`
  finds the requested lunar phase. Both use TT windows open on the left and closed
  on the right. Each result names its ephemeris. Callers using `events()` keep the
  2.0.0 longitude-crossing API. [Calc guide](../calc.md#station-and-lunation-search)
- **Conformance.** On Node 22.22.2, the shipped DE440 pack passes 639 of 640
  vectors in suite 0.3.0, including all 140 L4 event times. The astronomy-engine
  2.1.19 fallback passes 392 of 640, including 85 of 140 in L4. Both sources
  pass all 30 Mercury through Saturn station cases. Of 40 new or full Moon
  cases, DE440 passes 40 and the fallback passes 21. The unsupported case on
  both sources is a leap-second instant. [Conformance results](../../conformance/RESULTS.md)
- **Package size.** The archive holds 101 files, totaling 4,781,846 bytes
  unpacked. The package uses 1,462,294 of its 1,463,000 bytes beside the
  DE440 pack. The `./calc` import graph uses 201,118 of its 205,600 bytes
  beside the pack. [Size measurements](../evidence/2.1.0-20261123/package-size.json)

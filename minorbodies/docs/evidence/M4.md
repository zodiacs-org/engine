# M4 Chiron pilot evidence

The first held-out comparison passed the unchanged
`minorbodies-acceptance-v1` gates. This note records a finite pilot comparison,
not full-range accuracy, physical orbit uncertainty or an event-search result.

The fitted interval is 2000-01-01 TT inclusive to 2001-01-01 TT exclusive,
TT JD 2451544.5 to 2451910.5. `src/pilot-recipe.ts` and
`tests/pilot-recipe.test.ts` fix its 23 segments, degree 14, 391 training
epochs, 137 reference-speed centers and 641 independent reference epochs.
The latter include position-difference stencils outside the fitted endpoints;
only in-coverage epochs are evaluated by the fitted model. Training and
reference epochs, including all stencil samples, are disjoint.

The original source manifest SHA-256 is
`6fc7d1424f31e9e403daa5b85e4dce9c8ca9ba98e123a75bf89bc771ca4bacdc`.
Its generator/runtime/source hashes and every original response digest are
retained in `tests/fixtures/pilot/manifest.json`. The JPL solution identities
and redistribution record are in `SOURCES.md`.

The independent reference applies ERFA's IAU 2006/2000A rotation to the
held-out Horizons ICRF vectors. The evaluator uses the parent engine's
frame bias, IAU 2006 precession and IAU 2000B nutation. Reference speeds
are differences of separately obtained positions at plus/minus 0.005 TT day;
a plus/minus 0.01 TT-day stencil checks convergence. Horizons velocity columns
are not speed expectations. The script is `scripts/reference-erfa.py`; its
package versions are enforced by the script and checked in the report.

`tests/pilot-accuracy.test.ts` asserts these independent maximum-error gates
over the complete registered pilot corpus:

| Quantity | Enforced ceiling | Result |
| --- | --- | --- |
| Fitted ICRF direction | 0.05 arcsec | Passed |
| Ecliptic longitude | 1 arcsec | Passed |
| Ecliptic latitude | 1 arcsec | Passed |
| Distance | 1e-7 au | Passed |
| Longitude speed | 0.1 arcsec per TT day | Passed |
| Latitude speed | 0.1 arcsec per TT day | Passed |
| Distance speed | 1e-8 au per TT day | Passed |

These are the preregistered acceptance ceilings, not the observed maxima.
Fine/coarse reference differences passed a tenth of each speed ceiling.
All 22 internal joins passed the preregistered 1e-9 au position and
1e-9 au per TT day Cartesian velocity limits. Both direct and retrograde
reference states passed outside the speed-error allowance around zero.
The tests also deliberately bias a longitude and require the comparison to
fail, guarding against a disabled or self-referential accuracy gate.

Replay from `minorbodies/`, with Node 22.22.2 and the reference dependencies
installed as the companion README describes:

```sh
npm run pilot:build
npm run pilot:validate
npm run check
```

`pilot:validate` writes the complete measured maxima, their epochs, reference
convergence, seam errors and identities to ignored
`generated/pilot/accuracy-report.json`. The ERFA reference output and fitted
coefficients are also ignored. No live service is needed for replay. Missing
originals or reference dependencies fail; no astronomical test is skipped.

Recipe v1 failed intake before fitting or validation: a returned Julian date
did not exactly equal its requested printed epoch. V1 remains in the source;
v2 requests microday epochs and retains exact parser equality. Degree,
segment lengths, selection fractions and all acceptance limits are unchanged.
The initial large transport batches also received HTTP 502; smaller batches
preserve the same epoch sets. No held-out result was used to tune the fit.

Companion type checking, offline regeneration, bridge/evaluator tests,
independent accuracy tests, source replay checks and package exclusion checks
passed. The root package contents check cannot pass in this checkout because
`dist/calc.d.ts` is absent. No parent build or packed-file change was made.

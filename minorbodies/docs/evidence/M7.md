# M7 station search verification

The companion now searches installed minor-body longitude speed through the
engine's existing generic crossings solver. It retains TT endpoint conversions,
dataset and source identities, direction samples, event positions and whole-search
receipts. It does not copy the engine's event algorithm or change the parent
package, any fitted coefficient or the position acceptance limits.

## Independent reference scope

The retained [station reference intake](M7-station-reference.md) describes the
source captures and the recipe frozen before package station evaluation.
`src/station-reference.ts` reconstructs every request from independently reduced
Horizons positions, verifies the original bytes and source solutions, excludes
both training corpora, and uses the separate Python ERFA reduction. Reference
velocities are differences of reference positions, with converged stencils.
No package result supplies an expected station epoch or selects a reference
neighborhood.

`tests/station-accuracy.test.ts` checks both station directions of the retained
Chiron pilot over synthetic calendar year 2000 TT. The explicit full-data
`tests/full-stations.test.ts` checks every required body over the same reference
interval, using the full-range local datasets. The latter also checks searches
at installed coverage edges and refusal at the exclusive upper endpoint. Those
edge searches establish support handling, not independent event accuracy there.

`tests/station-accuracy-helper.ts` asserts the independently observed event
counts and directions and requires each reported TT epoch to fall within its
reference bracket expanded by the preregistered timing margin. At the held-out
epochs on both sides of each station, it separately asserts circular longitude
error and longitude-speed error against `ACCEPTANCE_POLICY`. The unchanged
limits are 1 arcsecond and 0.1 arcsecond per TT day, respectively. The reference
bracket width, timing margin and convergence gates are enforced by
`tests/station-reference.test.ts` and detailed in the intake note. These finite
comparisons are not a physical orbit error bound or a completeness proof over
the full installed interval. M11 remains the final full-range event corpus.

## Search mechanics

`tests/stations.test.ts` uses invented analytical speed functions and a trusted
synthetic provider. It checks both reversals, zero-speed touches, paired roots,
query endpoints, fractional TT epochs, the maximum coarse step, incomplete
direction support, empty windows and no extrapolation. It enforces the shared
provider-call budget during the solver, classification and event materialization,
including a failure after an earlier event. Every such refusal returns an empty
station list with a receipt. Tests also cover malformed fields, unavailable
bodies, time pins, local source identity, immutable receipts and no runtime
network request.

Review found that a nonzero mapped speed could become exactly zero after the
engine solver's angular normalization. The wrapper now checks that normalization
and refuses numerical resolution loss explicitly, with synthetic regression
tests. Native Node review also removed a TypeScript constructor parameter property
unsupported by type stripping. A source-checkout Node smoke run exercises the
public setup and README search example with runtime fetch disabled and checks
serializable receipts. No generated file or package build is needed by that run
beyond the existing local pilot coefficients.

The exact inclusive-end zero-speed case is an explicit limitation: a reversal
cannot be classified without a sample after that zero. All samples stay inside
the query, so the whole search refuses and names the unresolved candidate.
Extending the endpoint within installed coverage supplies the missing support.
An exact station at the exclusive start belongs to the preceding window.

## Reproduction

From `minorbodies/`, with Node 22.22.2 and the installed reference environment:

```sh
npm run check
node --experimental-strip-types scripts/capture-station-reference.ts --replay
npm run full:test
```

Default checks use the committed pilot and original station captures and fail
if the independent Python environment is missing. Full-data checks additionally
require the original ignored full datasets; they fail rather than skip when those
are absent. The unchanged full-accuracy and full-adapter gates passed this session;
after adding the station tests to that configuration, the added full-station file
also passed using `npm run full:test -- tests/full-stations.test.ts`.

The final check outcome is recorded in `PLAN.md`. The root package completeness
check remains blocked by the checkout's initially absent `dist/calc.d.ts`.
The separate scope check lists the root package with build hooks disabled and
confirms this folder is excluded. No root build or packed-file change was made.

# M10 local CLI verification

The companion exposes `position`, `stations`, `retrogrades` and `ingresses`
through `npm run --silent cli -- ...`. It delegates calculations to the
existing offline loaders, body adapter and event wrappers. No ephemeris,
event-search algorithm, coefficient, training source or accuracy limit changes.
All new files and edits stay in `minorbodies/`.

## Integration evidence

`tests/cli.test.ts` uses the retained original Chiron training sources to prepare
an evaluator in memory. It compares CLI output directly with library calls,
including full request, conversion, dataset, position and event receipts.
This does not use the package's previous output as astronomical truth and
establishes no additional accuracy or completeness claim.

The tests enforce exact labels, separate ISO and Julian-date input forms,
explicit Julian-date scales, shared endpoint pins, decimal/scientific numeric
syntax, event budgets and step constraints. Invalid and repeated flags,
malformed dates, mixed clocks and reversed intervals fail before data loading.
Explicit TT epochs survive Delta T pins, and equivalent ISO offsets calculate
the same physical epoch. Help bypasses loading. Injected missing-source and
verification errors check diagnostics without fabricating position receipts;
unexpected provider errors, including RangeError, remain calculation failures.

`tests/cli-process.test.ts` reconstructs the ignored pilot from retained
original sources, then launches the real script with the source resolver.
The launcher is tested from another working directory with fetch disabled.
The documented npm command reserves stdout for JSON. Tests compare position,
station, retrograde-window and ingress output with the library, preserve
explicit fractional TT input, and exercise offset ISO input under different
process timezones. Native invalid-input, budget and coverage failures check
the actual exit status and output channel. Importing the CLI module does not
execute a command.

`tests/full-cli.test.ts` requires the matching full source cache and generated
shards. It launches a position command for every required body and compares
the complete JSON result with its full-data adapter result. Vesta supplies a
nonempty ingress example, including retrograde motion and sign labels; the
Chiron pilot's ingress result in the tested interval is empty. Missing full
data fails this explicit suite rather than skipping it or using the pilot.

The integration interval in both process suites is TT JD 2451545.5 through
2451908.5, in synthetic calendar year 2000. Position inputs are fixed synthetic
epochs in those test files. These limited comparisons test the command
boundary only. Independent astronomical comparison scope remains in the M4,
M5, M7, M8 and M9 evidence notes and their Horizons/ERFA enforcing tests. M11
remains the final full-range validation milestone.

## Reproduction

Use the frozen Node runtime and reference environment described in the companion
README. From `minorbodies/`:

```sh
npm run check
npm run full:test -- tests/full-cli.test.ts
```

The default check includes the CLI parser, dispatch and native process suites,
existing independent pilot and event comparisons, source checks, TypeScript
and package exclusion. The filtered full-data command adds the required-body
and Vesta native checks. Coefficients, downloads and full reports remain ignored.
No live source capture is required by either command.

Both commands passed on Node 22.22.2. Review corrected the classification of
an internal RangeError after successful argument parsing; the regression test
now requires a calculation failure instead of an invalid-input diagnosis.
Native process tests also check the retrograde receipt's nested station-search
record rather than assuming all event receipts have the same shape.

The root `npm run package:contents` was attempted with its cache inside the
companion directory. It still fails because the initial checkout has no
`dist/calc.d.ts`. The separate package-exclusion check passes. No root build
was run, no packed file was changed, and no git metadata was modified.

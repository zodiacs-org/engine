# M8 retrograde-window verification

The companion assembles retrograde windows from the existing station search
and explicit TT endpoint speeds. It retains station provenance, endpoint
calculations, clipped-boundary information and whole-search receipts. No root
engine file, coefficient recipe, original source fixture or accuracy limit
changes for this milestone.

## Independent reference scope

`tests/retrograde-accuracy-helper.ts` uses the original held-out Horizons station
captures described in [the M7 intake record](M7-station-reference.md). Their
source identity and digest checks remain mandatory. The independent Python
ERFA reducer supplies the ecliptic positions; converged differences of those
positions supply reference speeds. Query endpoints and interior split points
come from this reference, without consulting this package's window output.

The expected negative episodes follow reference speed signs and independently
refined station brackets. Tests compare their station boundaries using the
unchanged timing allowance in `STATION_REFERENCE_RECIPE`. Reference endpoint
positions also enforce the unchanged longitude and longitude-speed arcsecond
limits in `ACCEPTANCE_POLICY`. The evidence applies only to the synthetic
calendar interval of the retained M7 corpus. It establishes neither physical
orbit uncertainty nor full-range event completeness. M11 remains pending.

`tests/retrograde-accuracy.test.ts` applies this check to the retained Chiron
pilot. `tests/full-retrogrades.test.ts` applies it to each required body using
the installed full dataset. Both exercise clipping and adjacent queries at
reference-derived epochs. The full-data test also exercises the start and an
instant near the end of installed coverage, and refusal at its exclusive end. Those
coverage-edge calls are integration checks, not independent accuracy evidence
at those epochs.

## Assembly and failure checks

`tests/retrogrades.test.ts` uses invented analytic speed functions with a
synthetic provider. It checks station-bounded and clipped episodes, adjacent
queries, zero-speed touches, exact endpoint zeros and fractional TT inputs.
The tests distinguish an isolated zero's instantaneous state from the enclosing
episode, and retain the station API's unsupported end-direction refusal.

The same tests check that station work, endpoint calculations and initial probes
share the caller's budget. A provider or budget refusal after a successful
station scan returns neither windows nor partial stations. Endpoint motion that
contradicts the station sequence also refuses. Receipts retain the actual work,
available endpoint records, original station evidence and source identities.
Malformed inputs, immutable snapshots and offline operation are checked too.

## Reproduction

From `minorbodies/` using the frozen Node runtime and reference environment
described in the companion README:

```sh
npm run check
npm run full:test
```

Default checks use the retained original pilot and station sources. Full-data
checks require the matching ignored caches and coefficient shards; absent data
fail instead of skipping. Complete reports and generated files remain ignored.
The outcome of this session's checks is recorded in `PLAN.md`.

The companion checks passed, and every full-data file passed in filtered runs
covering the existing accuracy, adapter and station suites and the new retrograde
suite. A native source-checkout smoke run exercised the README example with
runtime fetch disabled, checked aggregate sample accounting and round-tripped
the result through JSON. Review and synthetic tests also checked station times
rounded onto the query end, ensuring no zero-duration episode is returned.

The companion scope check lists the root package with build hooks disabled to
verify exclusion. The checkout still has no root `dist/calc.d.ts`, so the root
package completeness check cannot pass without a root build, which this task
does not authorize. No root build or packed-file change is made.
